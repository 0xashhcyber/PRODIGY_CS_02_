# Password Complexity Checker
A simple GUI tool to check the strength of user passwords using Python and Tkinter. Developed during my **Cybersecurity Internship at Prodigy InfoTech**.

 # Objective
To help users assess the strength of their passwords in real time and encourage strong password creation habits for better cybersecurity.

# Tech Stack
- Language: Python 3
- GUI Library: Tkinter
- Regex: For evaluating password rules

  # Features

- Real-time password strength feedback
- Clean and interactive GUI
- Color-coded strength results: **Weak**, **Medium**, **Strong**
- Encourages password best practices
